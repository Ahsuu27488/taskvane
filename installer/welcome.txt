Taskvane shows live CPU, GPU, memory, disk and network usage, temperatures and power draw. It's a lighter, more detailed alternative to Task Manager.

What gets installed
  - Taskvane, in Program Files, with a Start menu shortcut.
  - Optional: "Always start as administrator". This creates a scheduled task, so Taskvane can read CPU sensors without a UAC prompt each time it starts.

CPU temperature and CPU power also need the PawnIO driver, a small, digitally signed hardware driver used by LibreHardwareMonitor and other monitoring tools. It isn't included: install it from its author's site, https://pawnio.eu/ (the "Enable CPU sensors" button in Taskvane opens it).

Uninstalling removes Taskvane and its scheduled tasks. It doesn't touch PawnIO; uninstall that separately from Settings > Apps if you want.

Requirements: Windows 10 (version 1809 or later) or Windows 11, 64-bit.
